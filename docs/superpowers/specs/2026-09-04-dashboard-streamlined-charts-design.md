# 控制台移除系统配置矩阵与图表清晰直观重构设计文档 (Dashboard Streamlining: Stacked Charts & Interactive Latency)

**日期**: 2026-09-04  
**分支**: `main`  
**目标**: 移除控制台概览页面中的系统运行时参数矩阵；彻底解决请求总量、多模型分布与延迟图表现状杂乱不直观的问题。将图表区聚合为单一张全景 APM 大图表容器（支持流量趋势与延迟走势 Tab 切换）；流量图升级为“多模型分段堆叠柱状图 (Stacked Bar Chart)”以根绝线条与柱体冲突重叠；延迟图引入全网综合基底波形与“交互式图例悬浮高亮 (Legend Focus)”机制，实现清晰专业的数据洞察体验。

---

## 1. 现状痛点与重构动因

1. **线条穿插重叠，视觉极度混乱**：
   原图表 1 将总请求柱子/面积与多条多模型折线直接绘制在一起，五颜六色的折线在柱体内部穿行交织，失去视觉焦点；
2. **多模型延迟线条缺乏主次，形同乱麻**：
   原图表 2 中多达 4~8 个模型的毫秒耗时折线在一个纵轴区间内来回穿插重叠，无法辨别单条模型的实际波动情况；
3. **缺少交互过滤与聚焦**：
   图例仅为静态提示圆点，无法通过点击或悬浮筛选关注的模型；
4. **两张大图纵向堆叠过长**：
   两张 320px 高的图表连续向下排布，加上配置矩阵，页面纵向滚动过长，缺乏信息呼吸感。

---

## 2. 页面垂直层级规范 (Three-Tier Streamlined Flow)

彻底精简为三层清晰、现代的专业结构：

```
+-------------------------------------------------------------------------+
| Tier 1: 顶部 4 张 APM 核心指标卡 (系统状态 / 总请求量 / 平均延迟 / 可用率)        |
+-------------------------------------------------------------------------+
| Tier 2: 全宽模型性能与分布大矩阵 (置顶优先展示，多维数据表 + 移动端紧凑卡片)       |
+-------------------------------------------------------------------------+
| Tier 3: 综合全景 APM 大图表 (全宽自适应，Tab 切换：流量请求趋势 / 响应延迟走势)   |
|                                                                         |
| Tab 1: [ 📊 流量请求趋势 (Volume) ]                                      |
| - 多模型分段彩色堆叠柱状图 (Stacked Bar) + 总体平滑波形可选切换             |
| - 柱子总高 = 总请求数，柱内分段色彩 = 对应基准模型占比 (无交叉线干扰)         |
| - 悬浮卡片：总数、成功/失败比、按模型贡献降序的明细拆解                   |
|                                                                         |
| Tab 2: [ ⚡ 响应延迟走势 (Latency) ]                                     |
| - 基底：全网综合平均延迟贝塞尔平滑面积波形 (一眼掌握整体延迟水位)             |
| - 交互式图例：悬浮/点击单模型，独占高亮该模型耗时曲线，其余自动降噪淡化      |
+-------------------------------------------------------------------------+
```

## 3. 详细设计与核心算法

### 3.1 流量趋势——分模型堆叠柱状图算法 (Stacked Bar Algorithm)
在时间点 $i$ 的绘制中：
- 将全网总请求数 `p.total` 作为柱体总高度，纵向范围由 0 到 `volumeLimit`；
- 从基线 $yMax$ 开始向上累积：对于归一化后的模型列表中的每个模型 $m_k$，其数量为 $c_k = \text{getModelHourlyCount}(p, m_k)$：
  - 每一个分段的垂直高度 $h_k = (c_k / \text{volumeLimit}) \times \text{plottingHeight}$；
  - 绘制带有模型专属色彩的直方矩形，最顶部的分段给予圆角处理；
- **视觉效果**：零交叉折线，色彩分段清晰一目了然，高峰期由哪个模型引起一清二楚。

### 3.2 响应延迟走势——全网基底波形 + 交互式图例高亮 (Interactive Latency)
- **状态维护**：`focusedModel: string | null`（当前悬浮/聚焦的模型名称）；
- **全网综合基底波形**：
  - 以全体平均耗时 `p.avgDurationMs` 计算贝塞尔平滑三次曲线与柔和半透明渐变面积图作为基础背景；
- **多模型折线智能聚焦**：
  - 未聚焦时：各模型曲线以纤细、40% 半透明展现；
  - 鼠标移动至顶栏图例的某个模型（如 `gemini-3.8-flash`）时：
    - 该模型的线条立即加粗至 `3.5px`，不透明度提升至 100%，节点发光；
    - 其余模型的线条淡化至 10% 或隐藏；
    - 彻底实现“想看谁就看谁”的清晰直观体验。

### 3.3 移除系统运行时参数矩阵
- 彻底移除 `SystemRuntimeMatrix.tsx` 及其在 `DashboardView.tsx` 中的引用；
- 页面纵向空间得到大幅释放，结构干净规整。
