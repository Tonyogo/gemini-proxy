# 控制台页面通栏分层重构与模型矩阵全宽平铺设计文档 (Dashboard View Full-Width Layout & Merged Charts Design)

**日期**: 2026-09-04  
**分支**: `main`  
**目标**: 取消控制台页面原有的 6:4 栅格布局，采用垂直通栏分层流（Vertical Tiered Flow）；将“每小时请求量趋势”与“响应请求分布”合二为一，形成底色柱状/面积总流量与多模型分布曲线并存的综合全景大图；并将“模型性能与分布矩阵”平铺展开为全宽多维分析大卡片，展示更多模型性能与吞吐指标。

---

## 1. 现状痛点与重构动因

1. **6:4 栅格局限性**：
   原布局左侧 60% 挤压两张图表，右侧 40% 挤压模型矩阵与运行时配置。导致在常见 1080p 及宽屏下，图表横向时间轴密度过高，而右侧模型列表因宽度受限只能展示简单条目，信息量严重受制。
2. **图表维度割裂**：
   原布局中“请求量趋势”与“模型请求分布”分成两个图表/Tab。用户在观察某小时流量暴增时，需要反复切换或对照下方图表才能确认是哪一个模型在调用，割裂了关联分析。
3. **模型矩阵展示空间受限**：
   原模型性能卡片被约束在 340~420px 宽度内，进度条短窄，无法横向扩展诸如吞吐率（req/s）、性能健康度等关键 APM 维度。

---

## 2. 整体布局与架构重构 (Vertical Tiered Flow)

彻底取消 `grid grid-cols-1 lg:grid-cols-12` 栅格，重构为自上而下的通栏垂直分层流：

```
+-------------------------------------------------------------------------+
| Tier 1: 顶部 4 张 APM 核心指标卡 (系统状态 / 总请求量 / 平均延迟 / 可用率)        |
+-------------------------------------------------------------------------+
| Tier 2-A: 通栏综合大图表 (每小时请求总量 + 各模型请求分布平滑曲线)                   |
| - 底层：全网每小时请求量柱状直方图 / 面积底色 (支持形态切换)                           |
| - 上层：各模型专属品牌色平滑曲线与高亮点阵叠加                                          |
| - 悬浮卡片：总数、成功/失败比、各模型精确数量与占比明细                                   |
+-------------------------------------------------------------------------+
| Tier 2-B: 通栏响应延迟趋势大图表 (各模型每小时平均延迟 ms 曲线)                        |
+-------------------------------------------------------------------------+
| Tier 3: 全宽模型性能与分布综合分析大表格 (Model Performance DataTable)          |
| - 模型标识 / 请求总量 / 流量占比与大跨度流光进度条 / 平均延迟微晶 / 平均吞吐 QPS        |
+-------------------------------------------------------------------------+
| Tier 4: 通栏系统运行时参数微晶网格 (System Runtime Matrix: 6列自适应微芯片)        |
+-------------------------------------------------------------------------+
```

---

## 3. 核心功能与呈现规范

### 3.1 复合图表：请求总量与模型分布合一 (Merged Volume & Distribution Chart)
- **复合坐标体系**：
  - 同一时间 X 轴刻度，同一请求量 Y 轴区间；
  - **底层**：渲染每个时间周期的整体请求总量柱状图（带圆角，支持切换面积图），采用柔和低透明度背景渐变；
  - **上层**：为每个活跃模型绘制贝塞尔平滑三次曲线与彩色节点，直观展现多模型在各时间段对总流量的贡献分布。
- **标题工具栏与模型图例 (Legend)**：
  - 左侧：图表标题 + 状态指示点；
  - 右侧：模型色彩图例胶囊徽章（水平展开） + `[ 📊 柱状直方 | 📈 平滑面积 ]` 切换小药丸 + 当前时间点总数 Badge。
- **全景悬浮 Tooltip 微卡片**：
  - 呈现：选定时刻、全网总请求数、成功/错误比与比例条；
  - 呈现：每个模型在该时段的具体请求数及贡献占比百分比（如 `claude-3-5: 800 (60%)`），按请求量降序对齐。

### 3.2 通栏模型延迟品质图表 (Latency Trend Chart)
- 独立展示多模型平均响应耗时曲线（ms），通栏宽屏舒展展开，时间轴更清晰，彻底告别线条拥挤重叠。

### 3.3 全宽平铺模型性能矩阵 (`ModelPerformanceMatrix.tsx`)
平铺为 100% 全宽数据分析大卡片，以现代化 DataTable 排布多维指标：
1. **模型标识 (Model Identity)**：品牌色徽章 + 模型名称（支持完整复制与 Tooltip）
2. **请求总数 (Total Requests)**：千分位格式化数字徽章
3. **流量倾斜与流光进度条 (Traffic Share & Bar)**：
   - 精确百分比（如 `42.5%`）
   - 大跨度柔光色彩进度条（随容器宽度充分伸展，视觉冲击力强）
4. **延迟性能 (Avg Latency)**：带品质色彩的微晶徽章（`<1s` 绿、`<3s` 黄、`≥3s` 红）
5. **平均吞吐量 (Throughput)**：该模型在选定窗口内的平均处理速率（如 `0.32 req/s`）

### 3.4 底部通栏系统参数微晶 (`SystemRuntimeMatrix.tsx`)
- 采用全宽 6 列自适应网格（`grid grid-cols-2 sm:grid-cols-3 lg:grid-cols-6 gap-3`），收尾仪表盘，整齐对称。
