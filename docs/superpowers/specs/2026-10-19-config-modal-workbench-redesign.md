# 代理运行时系统配置页面 (ConfigModal) 现代化工作台重构设计规范

## 1. 概述与背景 (Intent & Why)

当前 Gemini Proxy 系统的核心管理控制台提供了一个动态运行时配置弹窗（`ConfigModal`）。随着网关节点多实例调度、直连模式 (Direct Mode) 密钥池轮询、出站通道代理切换 (Local Direct / Proxy Channel)、模型多目标重定向策略等特性的不断演进，配置项与交互维度显著增加。

现有实现的痛点：
- **布局局促拥挤**：采用传统的紧凑居中浮层和顶部横向滚动 Tab，在 PC 宽屏下未能有效利用可视空间，横向挤压严重。
- **信息噪音大**：上游网关节点（尤其是包含大量密钥池、允许模型列表的节点）完全平铺展示，多节点场景下一屏只能看到 1~2 个节点，频繁上下漫游。
- **缺乏变更高亮与操作感知**：用户修改多项配置后，难以一眼识别哪些被修改，保存按钮常驻底栏在长内容滚动时感知弱或容易误关。

本次重构旨在采用 **方案 A（现代化双栏全宽工作台 Linear / Vercel 风格）**，重构 `ConfigModal` 的视觉层级、响应式适配与交互体验，全面提升系统配置的管理效率与视觉品质。

---

## 2. 目标、非目标与负目标 (Goals, Non-Goals, Anti-Goals)

### 2.1 目标 (Goals)
1. **桌面端双栏工作台布局**：
   - 升级弹窗尺寸至宽幅工作台（`max-w-5xl`，高度 `85vh`），左侧为固定垂直导航栏，右侧为独立滚动的配置主内容区。
   - 导航栏集成图标、分类标题、简短说明以及动态状态指示（例如节点数、映射规则数、未保存变更点）。
2. **上游节点手风琴折叠（Accordion）与智能卡片**：
   - 每个网关节点采用可折叠卡片设计。默认折叠态展示紧凑摘要：状态圆点、节点备注、流量占比、运行模式胶囊、启用开关、展开折叠图标。
   - 展开后展示网关 URL、出口通道选择器、允许模型列表和密钥池文本域。支持“全部展开/全部折叠”快捷操作。
3. **脏检查与未保存变更浮动栏 (Dirty State Floating Bar)**：
   - 建立表单初始状态快照与实时比对，当发生任何字段变更时，在底部或侧边展示未保存变更提示，提供“放弃修改”与“保存应用”。
4. **移动端无缝降级适配**：
   - 在移动端（屏幕宽度 `< 640px`）自动降级为全宽抽屉/底部面板模式，导航平滑切换为紧凑胶囊横条，手风琴卡片针对触摸屏优化点击��域与交互间距。
5. **完整保留现有功能与多语言**：
   - 100% 保持所有配置项的读写逻辑、保存校验、默认值恢复、中英文多语言（i18n）以及深色/浅色主题适配。

### 2.2 非目标 (Non-Goals)
- 不修改后端的任何 API 接口（`/api/admin/status`、`/api/admin/config` 保持原样）。
- 不改变数据结构的 Schema 协议（如 `upstreamServers`、`modelMappings` 等在后端 `runtime.json` 中的存储格式）。

### 2.3 负目标 (Anti-Goals)
- **拒绝过度复杂化**：不引入庞大的第三方重型组件库，依托 Tailwind CSS 与现有的 `ui-card` / `ui-input` 设计体系，保持纯粹轻量。
- **拒绝破坏移动端可用性**：不能只顾 PC 端双栏而破坏移动端竖屏操作体验。

## 3. 详细设计与交互架构 (Detailed Architecture)

### 3.1 弹窗尺寸与栅格结构

```
+---------------------------------------------------------------------------------------+
|  Header: ⚙️ 代理运行时动态配置              [GitHub] [ESC / X]                       |
+--------------------------+------------------------------------------------------------+
| 侧边导航栏 (220px 固定)   | 主工作区 (自适应宽度，独立平滑滚动)                          |
|                          |                                                            |
| [ ] 通用与日志            | 标题区：当前分类名称 + 详细功能说明                         |
| [ ] 代理与上游   [3 节点] | ---------------------------------------------------------- |
| [ ] 系统指令与规则       | 配置卡片群 (ui-card-sub)：                                  |
| [ ] 模型映射    [12 规则]|  - 流量分配进度条                                          |
| [ ] 安全与重置           |  - 节点 1 (展开): URL, 出口通道, 密钥池, 允许模型           |
|                          |  - 节点 2 (折叠): Node 2 | 33% | Direct | 开关             |
| ------------------------ |  - 节点 3 (折叠): Node 3 | 33% | Proxy  | 开关             |
| 底部: [重置为 .env 默认] |                                                            |
+--------------------------+------------------------------------------------------------+
| [浮动/粘性底部栏] ⚠️ 检测到未保存改动 (3 项)            [放弃修改] [💾 保存并立即生效] |
+---------------------------------------------------------------------------------------+
```

### 3.2 导航侧边栏 (Sidebar Navigation)
- **Tab 列表项设计**：
  - 图标（`Sliders`, `Globe`, `FileCode`, `ArrowRightLeft`, `ShieldCheck`）。
  - 标题与副标题/计数徽���（如上游节点展示节点总数，映射展示规则条数）。
  - 激活态：采用深色/浅色优雅的高亮胶囊背景，左侧带有高亮指示条或纯色指示。
- **状态感知**：若当前 Tab 内部存在未保存的修改项，Tab 右侧显示轻量的微小指示圆点。
- **移动端适配**：通过 `hidden sm:flex` 与 `flex sm:hidden` 双轨布局，移动端在顶部保留横向滑动的 Linear 胶囊条，内容区铺满视口。

### 3.3 节点手风琴卡片 (Upstream Server Accordion)
- **折叠态卡片头**：
  - 节点状态指示（绿色/灰色指示灯）
  - 节点名称（若为空则显示 `Node N`）
  - 流量分配百分比胶囊（带各自专属色块）
  - 模式徽章（代理模式 / 直连模式）
  - 快捷操作：启用/禁用 Switch 开关、删除按钮、折叠/展开 Chevron 按钮
- **展开态卡片体**：
  - 节点名称输入框 & 权重滑动/数字输入框
  - 网关 URL 输入框（代理模式）
  - 出口通道选择器（本机直连 / 代理通道）
  - 允许模型（Allowed Models）输入框（带已配置模型数量标签 `×N`）
  - 直连密钥池（Direct API Keys）多行文本框（带密钥数量统计徽章）
- **批量操作栏**：在节点列表顶部提供“展开全部”、“折叠全部”以及“填入官方默认”快捷按钮。

### 3.4 脏检查与未保存状态管理 (Dirty Checking)
- **初始快照对比**：在获取到配置后记录 `initialConfigRef`（或序列化签名字符串）。
- **实时比对**：将当前表单字段状态（`systemRoleToInstruction`, `stripSystemFingerprints`, `ignoredTools`, `upstreamServers`, `modelMappings`, `logLevel`, `logRetentionDays`, `proxyUrl`, `countTokensModel`, `customSystemInstruction`, `ephemeralUserMessagesText`, `ephemeralSystemMessagesText`）与初始快照比对。
- **底栏常驻 + 修改高亮交互**：
  - **底栏常驻**：底部操作栏始终常驻可见，避免用户找不到保存位置。
  - **无修改状态**：左侧显示状态提示（如“配置与服务器同步”或快捷键提示 `⌘+S 保存`），右侧“保存应用”按钮呈现轻量/禁用就绪态。
  - **存在未修改状态 (Dirty)**：底栏变为强调/高亮模式，左侧显示醒目的黄色/琥珀色“存在未保存改动 (N 项)”指示，并提供“放弃修改”按钮（一键重置当前表单至打开时初始状态），右侧“保存应用”按钮呈现主色强调高亮态。
  - **弹窗关闭与快捷键**：顶部 Header 右上角与 ESC 键始终随时可关闭弹窗；支持 `⌘+S` / `Ctrl+S` 全局快捷键触发表单保存。

### 3.5 模型映射卡片优化 (Model Mappings)
- 保留 JSON 原始模式与可视化 KV 模式双向切换。
- 可视化模式中，规则卡片采用清晰的双向箭头连接（源模型 ➔ 目标模型），高阶配置（调度策略、HIGH 深度思考切换）整合为右侧紧凑的操作按钮群。
- 增加搜索/过滤输入框，当映射规则超过 5 条时，可快速按模型名称过滤。

## 4. 多语言与主题规范 (i18n & Theming)

- **主题体系对齐**：
  - 严格使用现有的 CSS 语义变量：`var(--bg-surface)`、`var(--bg-surface-sub)`、`var(--border-subtle)`、`var(--text-primary)`、`var(--text-secondary)`。
  - 移除原先硬编码的 `bg-slate-900/60` 等不透光生硬色彩，在浅色模式下自然渲染干净通透的 Slate 风格，在深色模式下呈现深邃高对比的沉浸质感。
- **多语言（i18n）**：
  - 补充新增的交互文案（如 `全部展开`、`全部折叠`、`未保存的变更`、`放弃修改` 等）至 `frontend/src/i18n/locales/zh.ts` 和 `en.ts`。

---

## 5. 迁移与兼容性保证 (Compatibility & Safeguards)

- 保持所有 Props（`isOpen`, `onClose`, `adminKey`, `onSaved`）不变。
- 键盘事件交互：支持 `Esc` 键退出（当有未保存改动时弹出放弃确认）、`⌘+S` / `Ctrl+S` 快捷保存。
- 保证 Jest 测试与 Vite 前端构建没有任何类型错误。
