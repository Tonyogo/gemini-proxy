# 控制台模型矩阵置顶优先展示与模型归一化设计文档 (Dashboard Model Matrix Top-Tier & Model Normalization Design)

**日期**: 2026-09-04  
**分支**: `main`  
**目标**: 优化控制台概览页面，将“模型性能与分布矩阵”和“系统运行时参数矩阵”提升至上方优先显示；实现模型名称智能归一化算法（将带有 `-high` 尾缀的模型如 `gemini-3.8-flash-high` 合并至基准模型 `gemini-3.8-flash`），并分别列出标准请求与 High 规格请求量；同时在移动端恢复上一版的经典卡片流设计，避免表格横向滚动。

---

## 1. 现状问题与重构动因

1. **信息阅读动线倒置**：
   开发者进入控制台概览最关心的往往是当前有哪些模型被调用、各模型性能和系统配置参数如何，原先置于最底部需要大幅向下滚动才能看到。
2. **模型名称碎裂冗余**：
   同一个物理模型（例如 `gemini-3.8-flash` 与 `gemini-3.8-flash-high`）因为请求时指定了不同的思考/推导模式尾缀，被拆分为多个完全独立的条目，分散了流量统计，无法直观了解该基准模型的全量负荷与 High 规格占比。
3. **移动端表格阅读体验生硬**：
   在手机等窄屏端，大宽度的数据表格只能依赖横向滚动查看，不如上一版单条精致卡片（上方信息横排、下方通栏流光进度条）易读易扫。

## 3. 模型归一化与 High 拆分算法 (Model Normalization)

### 3.1 核心解析规则
- **基准模型提取**：
  若模型字符串以 `-high` 结尾，去除尾缀得到基准名称：
  `rawModel = "gemini-3.8-flash-high"` -> `baseModel = "gemini-3.8-flash"`，其请求计入 `highRequests`；
  否则 `baseModel = rawModel`，其请求计入 `standardRequests`。
- **加权耗时聚合**：
  基准模型的平均延迟由该模型下所有普通和 High 请求的实际消耗时长加权汇总得出：
  `avgLatency = Math.round(totalDuration / durationCount)`。

### 3.2 字段定义 (`ModelStatItem`)
```typescript
export interface ModelStatItem {
  model: string;            // 基准模型名称 (如 gemini-3.8-flash)
  rawModels: string[];      // 关联的变体列表 (如 ['gemini-3.8-flash', 'gemini-3.8-flash-high'])
  requests: number;         // 总请求数 (standard + high)
  standardRequests: number; // 普通/标准请求数 (无尾缀)
  highRequests: number;     // 高规格/思考请求数 (带 -high)
  percentage: number;       // 流量占比 (0~100)
  avgLatency: number;       // 加权平均耗时 (ms)
}
```

## 4. 双态自适应呈现规范

### 4.1 桌面端全宽多维分析表格 (`md:block`)
在桌面端展示高密度 APM 分析大表：
- **模型名称**：彩色标识点 + 基准模型名（带 Tooltip 提示）；
- **标准请求 (Standard)**：数字格式化展示；
- **High 规格 (High)**：带紫色微晶胶囊提示（如 `[ ⚡ 380 ]`，若无则显示 `-`）；
- **总请求数 (Total)**：加粗醒目千分位数字；
- **流量占比与大跨度进度条**：百分比 + 丝滑伸展的彩色流光条；
- **平均延迟**：品质微晶徽章（`<1s` 绿、`<3s` 黄、`≥3s` 红）；
- **平均吞吐**：格式化 QPS 速率（如 `0.32 req/s`）。

### 4.2 移动端经典卡片列表 (`md:hidden`)
在移动端自动切换为上一版的经典简洁卡片流：
- **上层信息排布**：
  - 左侧：彩色指示圆点 + 基准模型名（截断） + 延迟微晶（`~410ms`）；
  - 右侧：请求分类明细（`1,420 / 380 High`） + 加粗全网占比 `38.5%`；
- **下层进度条**：
  - 左右撑满的平滑微光圆角条，单手滑动扫视清晰。
