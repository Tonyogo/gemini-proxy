# 产品功能全景地图 (Product Map)

本文件系统性梳理 Gemini Proxy 前端控制台的业务定位、功能模块、用户角色、系统边界及各模块业务价值。

---

## 1. 系统产品定位

Gemini Proxy 前端控制台（Gemini Proxy Console）是一个面向**开发者、运维工程师与 API 管理员**的专业级基础设施管理平台。

其核心价值：
1. **协议翻译与网关观测**：将 Claude Messages API 透明转换为 Google Gemini API，提供请求日志实时解构、Token 计量、延迟分析。
2. **多凭据高可用调度**：管理 Google OAuth / Service Account / API Key 凭据池，支持多账号激活、用量配额监控、并发调度与自动轮换。
3. **运维与交互工具箱**：提供基于 PTY 的交互式网页终端、流式日志追踪、全功能 API 调试器、多模型翻译评测工作台。

| :--- | :--- | :--- | :--- | :--- | :--- |
| **MOD-01** | **鉴权与会话 (Auth & Session)** | 保护管理后台安全，校验 `x-admin-key`，管理密钥持久化与主题/多语言预设 | 管理员 | 居中卡片表单 | 后端 `/api/admin/status` |
| **MOD-02** | **控制台概览 (Dashboard)** | 实时全景把控代理系统健康度、QPS、响应时长、错误率、模型调用分布与运行时配置 | 运维/架构师 | 仪表盘 (Dashboard) | `/api/admin/status`, `/api/admin/stats` |
| **MOD-03** | **账号与凭据管理 (Accounts)** | 管理多账号凭据生命周期、并发状态（激活/激活中/下线/禁用/失效）、用量配额，支持批量导入导出及自动去重 | 运维/管理员 | 列表 + 筛选 + 批量操作 | `/api/admin/accounts/*` |
| **MOD-04** | **请求日志与观测 (Logs & Inspector)** | 全生命周期流量审计，Chrome DevTools 风格双栏检查器，支持树形 JSON、SSE 逐帧重放、多轮会话气泡还原与 cURL 一键复现 | 开发者/排障人员 | 左右分栏 + 详情抽屉 (Inspector) | `/api/admin/logs`, `/api/admin/logs/:d/:h/:f` |
| **MOD-05** | **交互终端与日志流 (Terminal & Ops)** | 内置免 SSH 的 PTY 交互式 Linux 终端，支持移动端软键盘辅控条、代码片段库；并联服务端实时 SSE 日志流查看器 | 运维/开发者 | 全屏工作台 (Workbench) | `/api/admin/terminal/ws` (WebSocket), `/api/admin/terminal-logs` (SSE) |
| **MOD-06** | **API 调试操场 (Playground)** | Monaco 驱动的原始 JSON 请求体调试器，提供 4 种典型预设、实时流式打字机效果、JSON 树形预览及并发压力测试 | API 开发者 | 双栏工作台 + 弹窗 (Workbench + Modal) | `/v1/messages`, `/v1/messages/count_tokens` |
| **MOD-07** | **多模型翻译对比 (Translate Workbench)** | 针对中英技术文档的双语评测工作台，支持单模型精翻及最多 3 模型并行流式横向对比，对比延迟/Token吞吐速度 | 翻译测试/评测人员 | 左右对比工作台 (Comparison Workbench) | `/v1/messages`, `/api/admin/models` |
| **MOD-08** | **系统配置 (System Configuration)** | 在线热更模型映射、调度策略（least-used / round-robin / weighted）、超时控制、日志策略与敏感指令清洗规则 | 管理员 | 全局模态抽屉 (Config Modal) | `/api/admin/status`, `/api/admin/config` (POST) |

## 5. 用户角色与权限模型

目前系统基于单管理员密钥鉴权体系：
- **无鉴权访客 (Guest)**：若服务端未配置 `ADMIN_SECRET_KEY`，允许免密访问；若配置了密钥，所有接口拦截返回 401。
- **系统管理员 (Admin)**：在请求头携带 `x-admin-key`，具备系统完整读写控制权：
  - 上传、导出、删除账号凭据；
  - 查看全部请求载荷、Token、会话消息与 cURL；
  - 执行终端任意系统命令（以运行代理服务的宿主机用户权限）；
  - 动态修改代理配置、模型路由规则、重置配置至 `.env`。
